# Dataset attribution

The dialogue text and original persuasion strategy data come from
[PersuasionForGood](https://gitlab.com/ucdavisnlp/persuasionforgood/-/tree/90a3fd7b93437cec880e8f8192d26b144ecc493a),
released by Xuewei Wang, Weiyan Shi, Richard Kim, Yoojung Oh, Sijia Yang,
Jingwen Zhang, and Zhou Yu under the Apache License 2.0. A copy of that
license is included in [persuasionforgood-LICENSE](persuasionforgood-LICENSE).

This repository provides a subset of the conversations in a speaker-turn CSV
format with emotion and persuasion strategy fields. Cite
[Persuasion for Good](https://aclanthology.org/P19-1566/) and
[Empathetic Persuasion](https://aclanthology.org/2022.findings-naacl.63/)
when using this dataset.

The included Apache license applies to the upstream PersuasionForGood material;
it does not assign a license to other material in this repository.
